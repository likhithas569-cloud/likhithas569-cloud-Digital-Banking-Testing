# Test Evidence Screenshots

## Project

FinTrust Digital Banking Application


## Purpose

This folder contains screenshots captured during manual and automation testing execution.


## Evidence Types

Screenshots may include:

- Login validation results
- Test execution results
- Defect evidence
- Error messages
- Application behaviour verification


## Screenshot Naming Convention

Example:

TC_LOGIN_001_Login_Success.png

BUG_001_Transaction_Error.png


## Usage

Screenshots are attached to provide visual evidence for:

- Test execution
- Defect reporting
- Result verification
