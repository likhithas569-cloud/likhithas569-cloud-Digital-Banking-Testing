# Test Automation Framework - Digital Banking Application

## Project

FinTrust Digital Banking Application


## Purpose

This folder contains automation testing framework details for the digital banking application.

The automation framework is designed to automate critical user journeys and improve regression testing efficiency.


## Automation Tool

Selenium WebDriver


## Programming Language

Java


## Testing Framework

TestNG


## Build Tool

Maven


## Framework Design

The framework follows the Page Object Model (POM) design pattern.


## Automated Test Scenarios

The following scenarios will be automated:

- User Login
- Account Dashboard Validation
- Money Transfer Validation
- Logout Functionality
